# Hacker Marketing & Launch Plan

Tagline: **The One who Finds**

## Brand Identity

- Name: **Hacker**
- Ticker: **HACK**
- Core message: discover alpha early, build with community, protect holders with transparent controls
- Visual direction: dark terminal + neon accents, minimal logo mark, glitch/scanline motif

## Token Metrics Snapshot

- Supply: 1T HACK
- Buy/Sell tax: 5% / 8% (configurable within hard caps)
- Team vesting: 12-month linear
- Anti-whale: 1% wallet, 0.5% tx at launch

## Launch Roadmap

1. **Pre-launch (Week 1)**
   - Final audit pass + internal security checks
   - Publish tokenomics and setup docs
   - Seed social channels and ambassador cohort
2. **Testnet (Week 2)**
   - Sepolia deployment walkthrough
   - Community testing campaign and bug bounty-lite
3. **Mainnet launch (Week 3)**
   - LP creation and lock announcement
   - First exchange tracker submissions
4. **Post-launch (Weeks 4+)**
   - Weekly holder updates
   - Productized community utilities (quests/rewards)

## Social Messaging Framework

- Positioning line: “**Hacker — The One who Finds**”
- Content pillars:
  - Security transparency (pause/list controls, vesting stats)
  - Community wins (memes, holder milestones, clips)
  - Utility progress (campaigns, partner integrations)
- Cadence:
  - X/Twitter: 2–4 posts/day
  - Telegram/Discord: real-time moderation + daily recap

## Community Engagement Strategy

- Ambassador program with weekly missions
- Meme contests with on-chain reward proofs
- “Finders Board” leaderboard for referrals and on-chain tasks
- Bi-weekly AMA with roadmap checkpoint review

## Airdrop / Rewards Ideas

- Early tester reward: Sepolia participation snapshot
- LP supporter reward: time-weighted LP points
- Social quest rewards: verified task completion
- Anti-sybil controls: wallet age + activity thresholds
